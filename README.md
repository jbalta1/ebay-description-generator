# 🇬🇧 eBay Description Generator

Professional eBay listing generator for classic British car parts. Create formatted descriptions instantly with proper fitment info, condition details, and authentic British motoring terminology.

## Features

- 📝 Professional, formatted descriptions ready for eBay
- 🔧 Specialized templates for British classic car parts
- 📋 Copy with formatting preserved (Google Docs, Notes, etc.)
- ⚡ No installation - just open and use
- 🎨 Clean, responsive interface

## How to Use

1. Download `ebay-description-generator.html` and open in your browser
2. Fill in your part details (name, manufacturer, condition, fitment)
3. Click "Generate eBay Description"
4. Copy and paste into your listing

MG • Triumph • Austin Healey • Jaguar • Mini • Morris • Any British classic car parts
